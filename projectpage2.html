Environmental Simulator

A simulation game based on managing a cohesive environment.

Role Game Designer / Developer

Project Overview

This project focuses on translating the issues we suffer with in regards to global warming into a videogame format to help users better understand how actions affect the environment.

Key Mechanics & Technical Features
