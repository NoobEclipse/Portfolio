Project Overview

Project 1 was developed as an exploration into top-down action , UI experimentation, and scalable wave progression systems. The core gameplay loop requires the player to survive increasingly difficult waves of varied enemy types inside an enclosed space with varying abilities.

Special emphasis was placed on juice and game feel: camera shake triggers on impact, power-ups to boost progression, dynamic enemy systems and responsive directional aiming tied to the arrow key inputs.

Key Features & Systems

  • Custom 2D Controller: Vector-based movement, directional shooting .
  • Wave Spawner Logic: ScriptableObject driven spawn tables allowing custom enemy spawn rates, health multipliers, speed multipliers and boss waves.
  • Tilemap Level Architecture: Polygon collider-based environment layers allowing for dynamic line-of-sight and obstacle collisions.
